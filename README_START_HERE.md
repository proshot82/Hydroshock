# «Латунный янычар: Гидроудар» — запуск в Claude Code

## Что в архиве

| Путь | Что это |
|---|---|
| `BJ3_HANDOFF.md` | Вся история проекта, текущая точка, решения, план. Читать первым |
| `CLAUDE.md` | Постоянные правила для Claude Code (он читает его сам) |
| `START_PROMPT.txt` | Первый запрос, который нужно вставить в Claude Code |
| `docs/BJ3_WORLD_CANON_V2.md` | Сюжет, мир, персонажи, локи |
| `docs/BJ3_SKELETON_S3.md` | Все головоломки P01–P17 (утверждённый скелет) |
| `docs/BJ3_PUZZLE_CHAIN_PROMPT_V2.md` | Задание и формат детализации актов |
| `docs/DESIGN_BIBLE.md`, `docs/02_WRITING_BIBLE.md` | Канон серии |
| `docs/history/` | Справка, не источник |
| `MANIFEST_MD5.txt` | Контрольные суммы |

## Шаги

1. Распакуй архив в `C:\Янычар\`. Получится папка `C:\Янычар\bj3` — это и есть будущий проект игры. Папку `C:\Янычар\bj2` не трогай.
2. Открой Claude Code в папке `C:\Янычар\bj3`:
   - в настольном приложении Claude: вкладка Code → выбрать папку `C:\Янычар\bj3`;
   - или в терминале: `cd C:\Янычар\bj3`, затем `claude`.
3. Открой `START_PROMPT.txt`, скопируй весь текст и отправь его первым сообщением.
4. Claude Code сначала осмотрит папку и сверит документы, затем создаст репозиторий на копии инструментов из `bj2`, сделает солвер и предложит начать детализацию Акта I.

Ничего в файлах `docs/` руками не редактируй и не пересохраняй — иначе сломается сверка контрольных сумм.
