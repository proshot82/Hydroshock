# Строки интерфейса «Гидроудара»

Источник для сборки (`tools/web/build_web.py` → `data/ui.json`). В игру идут только строки вида `ключ | текст` (ключ — латинские строчные, цифры, «_»); остальное — пояснения.

> Черновик на чтение автору (план сборки, Р9 — «ok» автора 13.10.2026: строки пишет Claude, автор читает).
> Подписи кнопок титула — решение автора 13.10.2026 (В2). Остальное — по образцу BJ2 (`proshot82/bj2`, tools/gen_texts.py), под устройство BJ3:
> подсказка одна — кнопка «Совет предка» (GDD §10), панели целей нет; инвентарь — «ПРИ СЕБЕ» (слот `UI.inventory` Акта I).
> `%d` — число, подставляет движок. Правки — словами автора или прямо в этом файле.
