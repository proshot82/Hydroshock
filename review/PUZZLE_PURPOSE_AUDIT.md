# Ревизия загадок по двум вопросам автора (08.10.2026)

> Сводка вошла в самодостаточный документ аудита `docs/BJ3_PUZZLE_AUDIT.md` (§3–4); этот файл — первичный черновик.

Вопрос автора: «Все загадки в игре должны быть не ради загадки как таковой, а для продвижения по сюжету, приобретения необходимого предмета и т. д. Может быть, и другие загадки этому не удовлетворяют?» Повод — P10 «Наше / не трогать»: в нём нет ни выбора, ни усилия.

Каждая из 16 загадок проверена двумя вопросами:

1. **Зачем.** Что решение даёт для продвижения: проход, предмет или сведение, без которого следующий шаг невозможен. Сюда не засчитывается флаг «узнал», который нужен только затем, чтобы открыть разговор.
2. **Какое усилие.** Что игрок должен понять сам. Не засчитывается: решение — первое действие, которое игрок сделает и без мысли (клик по предмету); неудача сама показывает ответ; выбор из трёх строк, который проходится перебором.

Источники: сдачи `acts/act*/ACT*_SUBMISSION.md` (звенья Goal…New goal), графы `acts/act*/ACT*_graph.json` (requires/adds), тексты Акта II (`CHOICE.cause.*`).

## Системная проблема Акта II

Разговор с Изольдой (B14, P08) открывается только после девяти флагов «узнал». Среди них — итоги P04 (`knows_supply_cut`), P05 (`topology_known`, `photo_seen`), P06 (`seal_is_mark`), P07 (`name_revealed`, `paint_act_read`). В самом решении P08 из этого работает одно распоряжение о сокращении. Значит, P04, P06 и P07 для продвижения нужны, только чтобы закрыть список. Игрок этого не видит: Изольда просто «не готова» говорить, пока он не обойдёт все точки. Это и есть «загадки ради загадки», о которых спрашивает автор.

## Что предлагается (ждёт решения автора; всё — правка замороженных сдач)

1. **P10** — либо трап-мостик с мелом «НАШЕ» (его хочется выкинуть с хламом, без него колесо проваливается в щель порожка), либо снять как загадку и оставить вынос вещей действием.
2. **P06** — ширма из распахнутой юбки в решении уже есть, но это часть подъезда, а не вывод игрока; само открытие — клик по стеклу. Варианты: считать сценой (подъехал, нажал, увидел пломбу — сюжетное открытие остаётся) или придумать препятствие, которое клик не снимает. Второе требует нового проектирования звена, готового решения здесь нет.
3. **P04** — убрать выбор из трёх строк. Вывод игрок предъявляет действием: например, показывает Изольде, что табло всех барабанов и линия на камнях — одна минута (подносит доказательство), а не выбирает фразу. Либо слить P04 со сценой B01–B02 без отдельной проверки.
4. **B14** — оставить в обязательных требованиях разговора только то, что работает в самом убеждении (распоряжение о сокращении и пломба/подпись). Остальное сделать необязательным подкреплением реплик Изольды.
5. **P01, P12** — честно считать сценами (вступление и поворот), не загадками. Счёт игры — 14 загадок при принятии п. 1 (снять) и п. 2 (сценой), иначе 16.
