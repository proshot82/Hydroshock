**Почему прямоугольники (`rect_layer.py`).** Чтобы положить вещь, генератор сдвигает стопку бумаг; маска по разнице получалась рваной (старый и новый край стопки, островки перерисованного камня). Слой — весь участок варианта с мягким краем по камню; края участка совпадают с основой. У кружки из прямоугольника вырезан угол с маховиком: пломба и руки на маховике — другие слои.

**Порядок наложения.** Как записано в спеке §1.2 (архитектура → персонажи → предметы); добавлено: руки героя и щупальце в кадрах действий кладутся последними — они ближе всего к камере (рука с вантузом проходит над жетоном, руки на маховике — перед кружкой).
