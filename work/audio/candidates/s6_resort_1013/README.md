# Пакет З6 (13.10.2026): курортная тема вступления и тревожная вариация

Замечание автора 13.10.2026: тема в номере в начале — «более вальяжно курортная»; за мгновение до гидроудара музыка обрывается, удар — в тишине; после — вариация той же темы, тревожнее, но с юмором.

**Как сделано.** ElevenLabs Music v2.5 (`tools/audio/eleven.py`):
1. Тема — план из четырёх частей по 30 с (`plans/p*.json`; две части темы, две части вариации). Модель вторую половину сыграла почти той же — тональность и характер не сменились, поэтому из этих треков взяты только первые 50 с (`theme/`).
2. Вариация — новой частью «по образцу» (`conditioning_ref`: кусок темы 10–40 с, загруженный `eleven.py upload`, `song_ids.txt`): `plans/var_*.json`, сила образца high; для трёх тем ещё medium и low (`*_medium`, `*_low`) с явным «минором» в задании.
3. Проверка тональности программой (Крумхансл по хроме): во всех вариациях остался мажор, кроме `var_p2_hawaii_low` (соль минор вторым кандидатом). Тревога — инструментами и темпом.
4. Демо «как в игре» `listen/demo_*.mp3`: тема 38 с → обрыв 60 мс → 0,7 с тишины → `sfx_shock_thud` → вариация 45 с.

Стили: p1 — босса-нова (вибрафон, нейлон); p2 — гавайский шезлонг (стил-гитара, укулеле); p3 — черноморский санаторий 60-х (аккордеон, мандолина).
